DOMAIN SETUP NOW

Goal:
  sagarkerhalkar.com = public profile website on Cloudflare Pages
  monitor.sagarkerhalkar.com = private monitor app on local Windows server using Cloudflare Tunnel

Step A - Nameservers
  In GoDaddy paste the two nameservers shown in Cloudflare > sagarkerhalkar.com > Overview.
  Wait until Cloudflare shows domain Active.

Step B - Profile website
  Cloudflare > Workers & Pages > Create application > Pages > Upload assets.
  Upload folder: 01_PROFILE_WEBSITE_ONLY_DEPLOY_TO_CLOUDFLARE_PAGES
  Add custom domains: sagarkerhalkar.com and www.sagarkerhalkar.com

Step C - Monitor app
  On Windows server run 02_SYSTEM_HEALTH_MONITOR_ONLY_RUN_ON_LOCAL_SERVER\RUN_SERVER_2278.ps1
  Install autostart task using INSTALL_SERVER_AUTOSTART_TASK.ps1
  Cloudflare Zero Trust > Networks > Tunnels > Create tunnel.
  Public hostname:
    subdomain: monitor
    domain: sagarkerhalkar.com
    service: http://localhost:2278

Step D - Client commands after monitor domain works
Windows:
  mkdir C:\Temp -Force
  iwr https://monitor.sagarkerhalkar.com/scripts/BOOTSTRAP_WINDOWS_CLIENT_2278.ps1 -OutFile C:\Temp\BOOTSTRAP_WINDOWS_CLIENT_2278.ps1
  powershell -ExecutionPolicy Bypass -File C:\Temp\BOOTSTRAP_WINDOWS_CLIENT_2278.ps1 -ServerUrl https://monitor.sagarkerhalkar.com -IntervalSeconds 5

Ubuntu:
  curl -fsSL https://monitor.sagarkerhalkar.com/scripts/BOOTSTRAP_UBUNTU_CLIENT_2278.sh -o /tmp/bootstrap.sh
  sudo SERVER_URL=https://monitor.sagarkerhalkar.com INTERVAL_SECONDS=5 bash /tmp/bootstrap.sh
