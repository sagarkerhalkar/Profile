SAGAR PROFILE WEBSITE - STANDALONE

This folder is separate from the System Health Monitor project.
You can deploy this folder anywhere: Cloudflare Pages, GitHub Pages, Netlify, GoDaddy hosting, etc.

Files:
- index.html = public home profile
- cv/index.html = editable CV page
- projects/systemhealthmonitor/index.html = project page
- assets/profile_config.json = change name, title, skills, experience, contact, projects
- profile-editor.html = local editor to edit/download profile_config.json

How to customize CV/profile:
1. Open profile-editor.html on your PC.
2. Change skills, job title, projects, experience, phone/email/social links.
3. Click Download profile_config.json.
4. Replace assets/profile_config.json.
5. Upload/deploy this folder again.
