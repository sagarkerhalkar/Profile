Infrastructure observability case study

System Health Monitor Tool

Real-time Windows and Ubuntu fleet visibility designed around operational truth: hardware, software, networking, peripherals, alerts, history and safe client deployment.

Open live platformView GitHub

Operational problem

Labs and distributed education environments need clear visibility across mixed Windows and Ubuntu machines without hiding uncertainty behind invented values.

  • Live system status and last heartbeat
  • CPU, RAM, storage, GPU and networking
  • Installed software and USB/peripheral inventory
  • Change history, notifications and client messages
  • Windows and Ubuntu deployment diagnostics

Engineering principles

  • Show real vendor/OS data or N/A
  • Back up before change
  • Test one client before fleet rollout
  • Use human-readable operational data
  • Keep deployment and rollback commands documented

Architecture

Client collection, secure ingestion and operational dashboards.

Windows agent

PowerShell collection, scheduled task, hardware/software inventory and diagnostics.

Ubuntu agent

Bash/Linux collection, systemd service, network and hardware visibility.

Monitoring server

Python API, SQLite history, notifications, analytics, deployment and export workflows.
